# Hunter Hamra
These exercises refer to the academic website created during the week 5 workshop.
1.  Finish updating the sidebar by editing the `_config.yml` file. Add a profile picture by uploading a photo to the `images` folder and editing the associated line in the `_config.yml` file. Push these changes so that they are live on the website.
2.  The description on the homepage can be found in the `_pages` folder in the `about.md` file. Edit the `title` in the header, and then personalise the description (below the `---`) to be about yourself. Push these changes so that they are live on the website.
3.  The blogs on the website are in the `_posts` folder. Edit the header in the first blogpost file and then write a short personal reflection about the course so far (such as what you have learnt so far, what you have enjoyed or not, and what you look forward to.) Push these changes as well.
Once you've completed these steps, submit the URL of your website in fulfilment of the week 5 exercises.
